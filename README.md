# ONLY WITH ERMI

ONLY WITH ERMI is a community-powered website that helps users earn money by watching ads, accessing free and premium educational resources, and developing their skills in programming, AI, and more.

## Features

- Watch ads and earn rewards
- Login & signup system
- Access free and premium PDFs
- Free educational videos
- Smart search engine
- Supports Amharic and English languages
- Admin dashboard for content control
- Clean, professional UI (Google Ads ready)

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Coming soon)
- **Hosting:** GitHub + Netlify
- **Payment Integration:** Telebirr, CBE (Planned)
